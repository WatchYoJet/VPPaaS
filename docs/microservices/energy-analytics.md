# Energy Analytics API Documentation

This documentation describes the endpoints of the Energy Analytics microservice.

This API aggregates telemetry data across all assets and publishes the results to Kafka. Results are also persisted in the database for historical querying.

## GET /EnergyAnalytics

Retrieves all stored analytics records.

No payload is required for this endpoint.

> <details>
> <summary>Curl Example</summary>
>
> ```bash
> curl -X GET \
>   'http://<KONG_HOST>:8000/EnergyAnalytics' \
>   -H 'accept: application/json'
> ```
>
> </details>

<br>

Returns a JSON array of analytics records:

```json
[
  {
    "id": <integer>,
    "analyticsType": <string>,
    "dimensionKey": <string>,
    "value": <number>,
    "timestamp": <string>
  }
]
```

The `analyticsType` field identifies the metric. Possible values:

| analyticsType | dimensionKey | value |
|---|---|---|
| `energy-discharged-by-zone` | grid zone name | total kW discharged by batteries in that zone |
| `generated-energy-by-prosumer` | asset ID | total kW generated by solar panels |
| `consumed-energy-by-prosumer` | asset ID | total kW consumed by EV chargers |
| `average-soc` | `GLOBAL` | average state of charge across all batteries (%) |

## POST /EnergyAnalytics/compute

Triggers an analytics computation cycle. Fetches all current telemetry, aggregates it, persists the results, and publishes to Kafka.

No payload is required for this endpoint.

Published Kafka topics:

| Topic | Payload fields |
|---|---|
| `energy-discharged-by-zone` | `zone`, `discharged_kw`, `timestamp` |
| `generated-energy-by-prosumer` | `asset_id`, `generated_kw`, `timestamp` |
| `consumed-energy-by-prosumer` | `asset_id`, `consumed_kw`, `timestamp` |
| `average-soc` | `average_soc_percent`, `timestamp` |

> <details>
> <summary>Curl Example</summary>
>
> ```bash
> curl -X POST \
>   'http://<KONG_HOST>:8000/EnergyAnalytics/compute' \
>   -H 'accept: application/json'
> ```
>
> </details>

<br>

Returns a JSON object confirming the computation:

```json
{
  "computed": true,
  "timestamp": <string>
}
```
